# RAG Starter Kit

Production-ready retrieval-augmented generation (RAG) template for chatting with company documents, with evals included.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
![Status: in development](https://img.shields.io/badge/status-in%20development-orange)

> **Status:** in active development. Star or watch the repo to follow progress.

## Features

- Document ingestion for PDF, DOCX, HTML and Markdown
- Configurable chunking and embeddings
- Hybrid search (keyword + vector) with re-ranking
- Answers with source citations
- Evaluation suite for retrieval quality and answer accuracy
- Access control per document collection
- Docker Compose for local development

## Tech stack

- Python 3.11+
- FastAPI
- Azure OpenAI or open-source models
- pgvector or Azure AI Search
- Docker
